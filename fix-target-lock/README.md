# Fix Target Lock

[Builds](https://github.com/xWink/farever-mods/actions/workflows/build-fix-target-lock.yml) · [Releases](https://github.com/xWink/farever-mods/releases?q=fix-target-lock%2Fv&expanded=true)

Keeps the selected enemy locked for single-target skills and adds optional targeting controls.

## Features

- Use the game's existing target-lock binding to select or release an aimed target.
- Automatically unlock a dead target (enabled by default).
- Optionally allow switching targets while locked.
- Optionally disable automatic camera movement while locked.
- Enable quick casting to aim a ground-targeted skill while holding its key and cast on release.

Changing area or character clears the lock.

## Installation

Requires HLX Core 0.0.8+, [Better Mod Settings](../better-mod-settings/), and [Mod Update Alerts](../mod-update-alerts/). Follow the [installation instructions](../README.md#installation), then configure the mod in **Game Menu → Mod Settings**.

Also available on [Nexus Mods](https://www.nexusmods.com/farever/mods/8).

See [Building](../README.md#building) for source builds and tests.
