# v1.0.0

Initial release of More Audio Settings.

## Install

Copy `more-audio-settings.hl` to:

```text
Farever\hlx\mods\more-audio-settings\more-audio-settings.hl
```

Requires HLX Core.

## Behavior

- Alt-Tab away from Farever: game audio mutes.
- Return to Farever: previous game volume is restored.
- Does not modify the Windows volume mixer or other applications.
